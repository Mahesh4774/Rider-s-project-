# Rider's Project 🏍️

A twisty road finder for Kerala riders.

## What it does
- Fetches real routes between two Kerala locations
- Detects and scores twisty sections based on curve radius
- Identifies rhythm sections (left-right-left patterns)
- Calculates gradient and elevation data
- Visualizes everything on an interactive map

## Features
- Twisty section scoring (orange/red/darkred by intensity)
- Rhythm section detection with blue markers
- Gradient bonus for uphill sections and penalty for downhills
- Built for Kerala roads
